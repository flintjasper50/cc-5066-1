这是什么

从你提供的小纹理中枚举 B×B 图块，只在与已合成区域的重叠条带上 计算 SSD 相似度；在容差候选池中用带种子的随机抽取选块，再用动态规划最小割 在重叠区找最低代价切缝，而不是直线硬切，也不用模糊掩盖接缝。

周期连接如何求解

勾选“周期连接”后，网格按环面布置：最后一列图块的右重叠条带会与画布第 0 列 比较并做反向闭合切缝，最后一行同理。首尾约束在放置当时就进入 候选代价与最小割，而不是生成后裁掉一圈。可用 2×2 平铺检验。

两张样片锚点互斥时

“重排”会对外观容差内的候选预先计算切缝代价并改选最容易缝合的来源； “重采样”会重新抽取来源（同样片→邻接来源→任意来源）。所有尝试与随机数都记录在案。

受约束纹理扩展（框选种子）

勾选“受约束纹理扩展”后，在中间样本图上拖拽框选一块纹理， 它会被当作受保护种子直接落到画布左上角，只有框外的新像素由图块拼接生成。 可另加锁定细边（画布坐标，须在框选区内，永不重写）、 接缝禁区（每行一个矩形，只约束切缝路径、不产生孔洞）、 以及借用锁边端点（让相邻接缝从锁定边端点出发）。

生成后“指标与失败”页的扩展自检面板会核对：覆盖完整性（无孔洞）、 受保护像素恒等、锁定细边恒等、逐像素来源一致（画布像素等于样本 map_y,map_x 处像素）、 以及接缝/自然地板比值，并在叠加图上用蓝框标种子、绿框标锁边、红框标禁区。 禁区若把某条接缝端点整个围住而无法局部绕开，会记 resolved_by: none 且不制造孔洞。 这走的是同一个内核（quiltstudio.extend），失败自检会写进 run.json 并让状态转为 failure。

界面怎样启动

  • 在线生成模式：在本仓库根目录运行 python3 cli.py serve （等价于 python3 server.py），然后浏览器打开 http://127.0.0.1:8765。此模式下表单可调参、框选、点击“生成”并实时落库。
  • 只读模式：直接双击 web/index.html（file://）只能浏览已生成的 run，不能在线生成。
  • 离线预生成数据用 python3 run_all.py 产出，刷新页面即可看到全部 run。

生成限制（重要）

  • 全局像素指标无法判断语义：被切半的圆圈/箭头可能像素误差不高但视觉已坏。
  • 独特且唯一的大标记必然被复制或切碎；patch 小于标记尺度时大概率失败 （见 stress 组红色状态）。
  • 强定向条纹在相位错配时，最小割也只能给出锯齿切痕，周期闭合处更明显。
  • 候选池、阈值与随机种子决定结果；请查看同组所有种子而非只挑最好的一张。
  • 这是图块拼接/重排，不是超分辨率：放大画布靠的是新增图块，不是把小图拉大。

复现

每个 run 都保存了完整 run.json、source_map.npz （逐像素来源 sample/y/x 与 tile id）和种子。命令见“指标与失败”页。
